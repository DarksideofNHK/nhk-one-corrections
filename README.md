# NHK ONE 訂正一覧

NHK ONE の見逃し配信で、放送中の誤りがあった場面に映像へ重ねて表示される「訂正・お断り」を、**いま開いている回の一覧**にするブックマークレットです（非公式）。

```
この回の訂正・お断り（3件）
訂正 06:52〜 17秒  右下の会社名に誤り　正しくは「日本郵便」
訂正 08:56〜 21秒  右下の会社名に誤り　正しくは「日本郵便」
訂正 10:33〜 99秒  会社名に誤り　正しくは「日本郵便」
```

## 入れ方

**https://darksideofnhk.github.io/nhk-one-corrections/** を開き、ボタンをブックマークバーへドラッグします。

ドラッグできないときは、新しいブックマークを作り、URL 欄に [`dist/bookmarklet.txt`](dist/bookmarklet.txt) の中身を貼り付けます。

## 使い方

1. NHK ONE で見逃し配信の番組ページを開く（ふだんどおり、ご利用確認を済ませた状態で）
2. プレーヤーが表示されたら、ブックマークを押す
3. 右上に、この回の訂正・お断りが時刻つきで出る（もう一度押すと閉じる）

- 時刻は配信動画の頭からの時間です
- ページの中で別の回に移ったあとは、ページを読み込み直してから押してください
- 「テキストでコピー」で、番組名・ページの URL・出典つきの文字にできます
- 分類（訂正／補足／修正済み／お知らせ）は、文言のキーワードからのおおまかな推定です

## しくみ

見逃し配信のプレーヤーは、動画に付いている情報（JSON）の中の文言を、指定の時刻から指定の秒数だけ映像に重ねています。
訂正は映像に焼き込まれているのではなく、文字のデータです。

このブックマークレットは、**ページがすでに読み込んだその情報を読み直して**一覧にするだけです。

- 番組表の巡回や、ほかのページ・API へのアクセスはしません
- 映像・音声・字幕には触れません
- 読んだ情報はどこにも送りません

コードは [`src/nhk-one-corrections.js`](src/nhk-one-corrections.js)（約120行）です。`python3 build.py` で `dist/bookmarklet.txt` と `docs/index.html` を作り直します。

## 注意

- NHK とは関係のない非公式のツールです。NHK ONE の仕様が変わると動かなくなることがあります
- NHK ONE の利用には [NHKインターネットサービス利用規約](https://www.nhk.or.jp/rules/) が適用されます。自動で大量に取得するような使い方はしないでください
- 訂正の文言を紹介するときは、番組名と出典（NHK ONE）を添えてください
- NHK から求めがあれば公開をやめます

番組をまたいだ訂正の一覧（総合・Eテレ 東京、毎日更新）は [NHK WATCH](https://nhk-news-tracker.netlify.app/) の「放送の訂正」で見られます。
