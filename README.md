# NHK ONE 訂正一覧

NHK ONE の見逃し配信で、放送中の誤りがあった場面に映像へ重ねて表示される「訂正・お断り」を一覧にするツールです（非公式）。Chrome などの拡張機能と、ブックマークレットの2通りで使えます。

- 番組ページで押すと、**その回**の訂正を時刻つきで一覧にします
- パネルのボタンで、**その日の総合・Eテレの全番組**の訂正を一覧にできます（前の日・次の日、全国51地域に切り替えられます）

```
9月29日（火） 総合（東京）の訂正・お断り
見逃し配信 57本を確認。2番組に4件

06:30 NHKニュース おはよう日本 台風26号 進路の見通しと影響は
  訂正 ▶ 06:52〜 17秒 放送 06:36:52  右下の会社名に誤り　正しくは「日本郵便」
  訂正 ▶ 08:56〜 21秒 放送 06:38:56  右下の会社名に誤り　正しくは「日本郵便」
  訂正 ▶ 10:33〜 99秒 放送 06:40:33  会社名に誤り　正しくは「日本郵便」
20:45 首都圏ニュース845
  訂正 ▶ 09:59〜 11秒 放送 20:54:59  正しくは関西電力を含む10社すべて
```

## 入れ方

拡張機能とブックマークレットの2通りあります。中身は同じです。

### 拡張機能（Chrome・Edge・Brave など）

1. [Releases](https://github.com/DarksideofNHK/nhk-one-corrections/releases/latest) から `nhk-one-corrections-extension-*.zip` をダウンロードして展開する
2. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選ぶ
4. ツールバーの「訂」のボタン（パズルのアイコンからピン留めしておくと便利）か、Alt+Shift+T で開く・閉じる

権限は `activeTab` と `scripting` だけです。ボタンを押したタブの中でしか動きません。

### ブックマークレット

**https://darksideofnhk.github.io/nhk-one-corrections/** を開き、ボタンをブックマークバーへドラッグします。

ドラッグできないときは、新しいブックマークを作り、URL 欄に [`dist/bookmarklet.txt`](dist/bookmarklet.txt) の中身を貼り付けます。

## 使い方

まず、NHK ONE で見逃し配信を見られる状態にしておきます（ふだんどおり、ご利用確認を済ませた状態）。

| どこで押すか（拡張機能のボタン・ブックマーク） | 出るもの |
|---|---|
| 見逃し配信の番組ページ | その回の訂正・お断り。「この日の総合の全番組」ボタンで、その日の一覧へ |
| 日付ごとの番組一覧のページ（`/tv/pl/schedule-tep-g1-130-20260929/list` など） | その日の全番組の訂正・お断り |
| NHK ONE のそのほかのページ | 今日の総合の全番組の訂正・お断り（自分の地域） |

- その日の一覧は、ご利用確認で選んだ地域で出ます。一覧の地域の欄で、ほかの地域（地方局の番組）に切り替えられます
- ▶ は配信動画の頭からの時間、「放送」は放送された時刻です
- 番組名を押すと、その番組のページが開きます
- 「テキストでコピー」で、番組名・ページの URL・出典つきの文字にできます
- 分類（訂正／補足／修正済み／お知らせ）は、文言のキーワードからのおおまかな推定です
- 見逃し配信の期間（おおむね1週間）を過ぎた日は出ません

## しくみ

見逃し配信のプレーヤーは、動画に付いている情報（JSON）の中の文言を、指定の時刻から指定の秒数だけ映像に重ねています。
訂正は映像に焼き込まれているのではなく、文字のデータです。

ボタンを押したときに次のものを読みます。

- NHK ONE のページ（ブラウザで開くのと同じもの）を1回。ここに各回の動画情報の場所が書いてある
- 各回の動画情報。その回だけなら1件、その日の全番組なら1チャンネルで約60件（1件数 KB）

定期的な巡回はしません。映像・音声・字幕には触れません。読んだ情報はどこにも送りません。

コードは [`src/nhk-one-corrections.js`](src/nhk-one-corrections.js) の1つです。`python3 build.py` で、ブックマークレット（`dist/bookmarklet.txt`・`docs/index.html`）と拡張機能（`extension/`・配布用の zip）を作り直します。拡張機能は、ボタンを押したタブにこのコードを差し込むだけです（[`extension/background.js`](extension/background.js)）。

## 注意

- NHK とは関係のない非公式のツールです。NHK ONE の仕様が変わると動かなくなることがあります
- NHK ONE の利用には [NHKインターネットサービス利用規約](https://www.nhk.or.jp/rules/) が適用されます。短い間に何度も押すような使い方はしないでください
- 訂正の文言を紹介するときは、番組名と出典（NHK ONE）を添えてください
- NHK から求めがあれば公開をやめます

番組をまたいだ訂正の一覧は、[NHK WATCH](https://nhk-news-tracker.netlify.app/) の「放送の訂正」でも見られます（総合・Eテレと、総合の地方局の番組の「訂正」、毎日更新）。
