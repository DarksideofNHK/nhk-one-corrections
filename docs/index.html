NHK ONE 訂正一覧

NHK ONE の見逃し配信では、放送で誤りがあった場面に「右下の会社名に誤り　正しくは〜」のような文言が映像に重ねて表示されます。 このツールは、その回や、その日の全番組の訂正・お断りの文言を時刻つきで一覧にします。非公式のツールです。

拡張機能で使う（Chrome・Edge など）

  1. Releases から nhk-one-corrections-extension-*.zip をダウンロードして展開する
  2. chrome://extensions を開き、右上の「デベロッパー モード」をオンにする
  3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選ぶ
  4. ツールバーの「訂」のボタンか、Alt+Shift+T で開く・閉じる

権限は activeTab と scripting だけで、ボタンを押したタブの中でしか動きません。

ブックマークレットで使う

下のボタンを、ブラウザのブックマークバーへドラッグしてください。

NHK ONE 訂正一覧

ドラッグできない環境では、新しいブックマークを作り、URL 欄に次のコードを貼り付けます。

使い方

  1. NHK ONE で見逃し配信を見られる状態にする（ふだんどおり、ご利用確認を済ませた状態）
  2. NHK ONE のページで拡張機能のボタン（Alt+Shift+T）かブックマークを押すと、右上にパネルが開きます
  3. 番組ページなら「この回」、それ以外なら「この日の一覧」が出ます。上のタブで切り替えられます
  • 「この日の一覧」は「総合／Eテレ」、地域、直近8日の日付で切り替えます。総合の地域で「全国（地方局も）」を選ぶと、全国の地方局の番組も読みます（30〜40秒）
  • 一度読んだ日の結果はブラウザに残り、日付を行き来してもすぐ出ます。新しい訂正を確かめたいときは ↻ で読み込み直します
  • 種類（訂正・補足・修正済み・お知らせ）で絞り込めます。← → で日付を移動、Esc で閉じる、— で小さくできます

ログインしていないと NHK ONE が「アカウント登録のお願い」を出すことがあります。開いているあいだはパネルも操作できないので、閉じてください。▶ は配信動画の頭からの時間、「放送」は放送された時刻です。

何をしているか

  • 番組ページのプレーヤーは、動画に付いている情報（JSON）の中の文言を、指定の時刻から指定の秒数だけ映像に重ねています。訂正は映像ではなく文字のデータです
  • ボタンを押したときに、NHK ONE のページ（ブラウザで開くのと同じもの）を1回と、各回の動画情報を読みます。その回だけなら1件、その日の全番組なら1チャンネルで約60件です
  • 定期的な巡回はしません。映像・音声・字幕には触れません。読んだ情報はどこにも送りません
  • 「訂正」「補足」「修正済み」「お知らせ」の分類は、文言のキーワードからのおおまかな推定です

注意

  • NHK とは関係のない非公式のツールです。NHK ONE の仕様が変わると動かなくなることがあります
  • NHK ONE の利用には NHKインターネットサービス利用規約 が適用されます。短い間に何度も押すような使い方はしないでください
  • 訂正の文言を紹介するときは、番組名と出典（NHK ONE）を添えてください
