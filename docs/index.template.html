NHK ONE 訂正一覧

NHK ONE の見逃し配信では、放送で誤りがあった場面に「右下の会社名に誤り　正しくは〜」のような文言が映像に重ねて表示されます。 このブックマークレットは、いま開いている回に入っている訂正・お断りの文言を時刻つきで一覧にします。非公式のツールです。

入れ方

下のボタンを、ブラウザのブックマークバーへドラッグしてください。

NHK ONE 訂正一覧

ドラッグできない環境では、新しいブックマークを作り、URL 欄に次のコードを貼り付けます。

使い方

  1. NHK ONE で見逃し配信の番組ページを開く（ふだんどおり、ご利用確認を済ませた状態で）
  2. プレーヤーが表示されたら、ブックマークの「NHK ONE 訂正一覧」を押す
  3. 右上に、この回の訂正・お断りが時刻つきで出ます。もう一度押すと閉じます

時刻は配信動画の頭からの時間です。「テキストでコピー」で、番組名・ページの URL・出典つきの文字にできます。

何をしているか

  • 番組ページのプレーヤーは、動画に付いている情報（JSON）の中の文言を、指定の時刻から指定の秒数だけ映像に重ねています
  • このブックマークレットは、ページがすでに読み込んだその情報を読み直して一覧にするだけです。番組表の巡回や、ほかのページへのアクセスはしません
  • 映像・音声・字幕には触れません。情報はどこにも送りません
  • 「訂正」「補足」「修正済み」「お知らせ」の分類は、文言のキーワードからのおおまかな推定です

注意

  • NHK とは関係のない非公式のツールです。NHK ONE の仕様が変わると動かなくなることがあります
  • NHK ONE の利用には NHKインターネットサービス利用規約 が適用されます。自動で大量に取得するような使い方はしないでください
  • 訂正の文言を紹介するときは、番組名と出典（NHK ONE）を添えてください
